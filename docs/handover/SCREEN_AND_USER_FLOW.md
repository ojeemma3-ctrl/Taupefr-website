# TaupeFR — Original Screens and User Flow

## Original screen inventory

| Screen | Purpose | Key content / interactions |
|---|---|---|
| Landing / Welcome | Explain TaupeFR and invite the student into the product | Brand promise, introduction, start action |
| Journey | Make the overall move-to-Bordeaux journey understandable | Admission, accommodation, arrival, administration, marketplace/furniture, community, settled |
| Profile | Capture relevant student context | Study/arrival and support information; editable answers |
| Dashboard | Give the student a central overview | Journey overview, relevant actions, links to modules |
| Housing | Help students navigate accommodation options | Search resources, preparation, scam awareness, trusted links |
| Arrival | Help students prepare for and manage arrival | First priorities, local orientation and practical information |
| Administration | Explain relevant administrative topics | Organised checklist, simple explanations, official sources |
| Marketplace | Demonstrate student-to-student exchange | Categories and illustrative sample listings |
| Community | Help students discover peer support | Student communities, groups and support resources |
| Settled | Support ongoing life in Bordeaux | Local resources, opportunities and community |

## Original broad journey

1. **Admission** — student receives or prepares for university admission.
2. **Accommodation** — student understands housing options and prepares a search.
3. **Arrival** — student prepares to travel and arrives in Bordeaux.
4. **Administration** — student explores relevant administrative steps.
5. **Furniture / Marketplace** — student can discover second-hand essentials and exchange opportunities.
6. **Community** — student connects with other students and local support.
7. **Settled** — student has ongoing access to useful local and student-life information.

This is a high-level product journey. Do not encode it as a compulsory legal or administrative sequence.

## Example original demo flow

1. Open the landing page.
2. Select the action to start or explore TaupeFR.
3. Enter or select a sample student profile.
4. Open the dashboard.
5. Explore the journey overview.
6. Open Housing and view a guide or trusted resource.
7. Open an Administration topic and view its steps and official source.
8. Open the Marketplace and browse sample categories.
9. Open the Taupe Assistant and ask what to do next.
10. Explore Community or Settled.

## UX rules

- Keep navigation consistent across screens.
- Make the next useful action easy to find.
- Use clear labels rather than unexplained French administrative acronyms.
- Keep content scannable.
- Show where information comes from.
- Make it clear when a resource opens an external service.
- Avoid fake live data.
- Use sample student data only as a demonstration and label it as such.
