# TaupeFR — Original Design and Interaction Guide

## Brand

**TaupeFR**  
**“Your Home. Your Start. Your France.”**

The brand should feel like a reliable companion for a student moving to a new city.

## Visual personality

- Welcoming.
- Clear.
- Reassuring.
- Contemporary.
- Trustworthy.
- Student-friendly.
- Premium in execution but accessible in tone.

Use the existing project logo, palette, typography and components from the repository if present. Do not replace them without first understanding why they were chosen.

## Interface principles

1. Clear visual hierarchy.
2. Readable body text.
3. Consistent spacing and alignment.
4. Simple labels and obvious actions.
5. Purposeful cards and panels.
6. Consistent buttons and form controls.
7. Good mobile usability.
8. Minimal decorative effects.
9. Avoid generic AI dashboard clichés.
10. Avoid overwhelming students with too many competing elements.

## Interaction patterns

- Clickable journey steps.
- Editable student profile.
- Dashboard state based on sample profile information.
- Expandable or navigable guidance details.
- Checklists for task progress.
- Clear external-resource links.
- Reusable Taupe Assistant entry point.
- Marketplace category browsing with illustrative sample listings.
- Confirmation and empty states where appropriate.

## Content tone

Use simple, respectful and practical language.

Prefer:
- “What you need to know”
- “Why this matters”
- “What to prepare”
- “Steps to follow”
- “Where to do it”
- “Check the official information”

Avoid:
- Overpromising.
- Legal certainty where requirements vary.
- Long blocks of unexplained administrative language.
- Marketing-heavy slogans inside task guidance.

## Responsive behaviour

Design desktop and mobile intentionally:
- Mobile navigation must be easy to use.
- Buttons and tap targets must be comfortable.
- Cards should stack cleanly.
- Text must remain readable.
- Avoid horizontal scrolling.
- Important task actions should remain easy to reach.
